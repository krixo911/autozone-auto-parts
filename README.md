# AutoZone — Auto Parts & Accessories

**Internship Task:** WD-EC-006  
**Student Code:** DAS-EC-006  
**Company:** Data Alcott Systems  
**Domain:** E-Commerce Auto Parts

A responsive frontend-only automotive e-commerce demo built with HTML5, CSS3 and vanilla JavaScript. No database or real payment gateway is used.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser. (For best results, use VS Code Live Server.)
3. Internet access is needed for Google Fonts and remote Unsplash product/hero images.

## Features
- Responsive home page and mobile navigation
- Product grid with search, category, brand, vehicle and sort filters
- Product detail modal and compatibility information
- Add to cart, quantity changes, remove item and automatic totals
- Wishlist saved in localStorage
- Vehicle selection and fitment filtering
- Simulated login/register and order history
- Checkout form with COD / UPI demo / card demo options
- Simulated order confirmation; no real payment is collected
- Contact form interaction
- Cart, wishlist, user and orders persist in browser localStorage

## Project structure
- `index.html` — page structure and sections
- `style.css` — styling, responsive breakpoints and visual design
- `script.js` — product data and application logic
- `PROJECT_REPORT.md` — project report

## Technology
HTML5 · CSS3 · JavaScript (ES6) · localStorage

## Deployment
Publish the repository with GitHub Pages:
1. Push all project files to a **public** GitHub repository.
2. Open repository **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. Wait for the published URL to appear in the Pages panel.

You can also deploy the folder using Netlify or Vercel static hosting.
